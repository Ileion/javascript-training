## 🎓 What's Included in Your Course

### 6 Complete Lessons (90 minutes total)
1. **Introduction to JavaScript** (5 mins)
   - What is JavaScript and why learn it?
   - Applications and use cases

2. **Variables & Data Types** (15 mins)
   - var, let, const differences
   - String, Number, Boolean, Object, Array, etc.
   - typeof operator

3. **Operators & Control Flow** (15 mins)
   - Arithmetic, comparison, logical operators
   - if/else/else if statements
   - Switch cases and ternary operator

4. **Functions** (15 mins)
   - Function declaration and calls
   - Arrow functions (ES6)
   - Parameters, return values, scope

5. **Arrays & Objects** (15 mins)
   - Array creation and methods (push, pop, map, forEach)
   - Object properties and methods
   - Iteration and access patterns

6. **DOM & Events** (15 mins)
   - Selecting HTML elements
   - Modifying content and styles
   - Event listeners and handlers
   - Creating/removing elements

### 6 Interactive Exercises
- Exercise 1: Working with Variables
- Exercise 2: Conditionals (Even/Odd Checker)
- Exercise 3: Writing Functions
- Exercise 4: Loops
- Exercise 5: Working with Arrays
- Exercise 6: DOM Manipulation

### Interactive Features
- **Live Code Sandbox** - Write and execute JavaScript in real-time

- **Exercise Interface** - With hints and solution toggles
- **Responsive Design** - Works on desktop, tablet, and mobile

## 🔧 Customization Guide

### Want to Add More Lessons?
1. Edit `lessons.js`
2. Add a new object in `lessonsContent`
3. Add a new lesson-card div in `index.html`

### Want to Add More Exercises?
1. Edit `exercises.js`
2. Add a new exercise in `exercisesContent`
3. Add a new exercise-card div in `index.html`

### Want to Change Colors?
1. Edit `styles.css`
2. Modify the `:root` color variables
3. Save and refresh browser

### Want to Change Content?
1. Edit the HTML content in lesson/exercise objects
2. Change the text, code examples, descriptions
3. Save and test
